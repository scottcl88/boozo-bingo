# Security Policy

## Reporting a vulnerability

Please report security issues **privately** using GitHub's *Report a vulnerability* button on this repository's Security tab (private vulnerability reporting). Do not open public issues, discussions or pull requests for security problems.

Include: affected file/version, steps to reproduce, impact, and any suggested fix.

## Disclosure process

- Acknowledgement: best effort within 7 days.
- Assessment and fix: timeline depends on severity; this is a personal project maintained on a best-effort basis.
- Coordinated disclosure: please allow a reasonable period (90 days by default) for a fix before any public disclosure. Credit is given on request.

## Scope and data handling

- Do not access, modify or exfiltrate data that is not yours, and do not degrade any live service.
- Please do not include secrets or personal data in reports beyond what is needed to reproduce.
- No bug bounty is offered.

## Supported versions

Only the default branch is supported.

## AI-assisted development

Parts of this repository were created with AI assistance and reviewed by the maintainer. AI-generated code may contain mistakes; please report anything suspicious.
